# PROJECT: DEADLOCK PROTOCOL
### The Definitive Malicious Anti-UX Game Interface & Tactical Combat Sortie
*A masterclass in pure malice, hostile digital architecture, and engineered user cognitive fatigue.*

---

## 🎮 Overview

Modern game UI design is grounded in ergonomics, friction reduction, and intuitive visual cues. **Project: Deadlock Protocol** subverts every single rule. Designed to look and feel like an authentic, poorly-ported, bureaucratic multiplayer military tactical client from a bankrupt publisher, it is technically 100% functional—yet engineered at every pixel to maximize irritation, confusion, and cognitive fatigue.

---

## 🧪 Core Anti-UX Features & Hostile Mechanics

### 1. Depressing & Jarring Visual Palette
- **Muddy, Sterile & Harsh Clashing Colors**: Sickly olive greens (`#1d2417`, `#384521`), stale dirty beige (`#d1c7b7`), unrefined pure cyan (`#00FFFF`), harsh magenta (`#FF00FF`), and glaring pure yellow (`#FFFF00`).
- **Simulated Hardware Glitches**: Dynamic screen-tearing scanlines that horizontally displace panels, fake dead pixel clusters permanently anchored in active reading corridors, and CRT burn-in ghost watermarks.

### 2. Typographic Disaster & Grid Violations
- **5 Clashing Typefaces**: Victorian Cursive (`Alex Brush`), ultra-compressed technical sans (`Barlow Condensed`), book serif (`Times New Roman`), brutalist all-caps (`Impact`), and raw monospace (`Courier Prime`).
- **Grid Subversion**: Every card, modal, and badge is intentionally displaced by **3px to 7px off-center** with asymmetrical borders. High-opacity security seals physically overlap and obscure item lore.

### 3. The Deceptive "Worst" Buttons & Microscopic Hitboxes
- **Inverted Color Psychology**: Positive action buttons (*Confirm / Equip*) are styled in flat, dull grey with a `not-allowed` disabled appearance. Catastrophic destructive actions (*Purge / Destroy All Data*) are rendered in vibrant, inviting, pulsing neon green (`#00FF66`).
- **Hitbox Drift (Cursor Evasion)**: Hovering within 90px of key action buttons causes them to dynamically flee 18–25px away from the pointer.
- **Microscopic 2x2px Active Hitbox**: Large 340px × 60px buttons only trigger if the user clicks a microscopic 3px × 3px center dot. Clicks outside calculate Euclidean distance and display: `HITBOX MISSED BY 42.8px! CALIBRATE MOUSE.` alongside a harsh 160Hz error buzz.

### 4. Obnoxious Confirmation Traps (The 3-Step Gauntlet)
- **Step 1**: Deceptive button swap (*Abort* is bright green; *Proceed* is washed-out grey).
- **Step 2**: Mandatory **10.0-second unpauseable countdown**. Moving the mouse outside the modal perimeter immediately **resets the timer to 10.0s**.
- **Step 3**: Biometric confirmation slider with **inverted drag physics** (dragging mouse right forces the handle to move left).

### 5. Playable Tactical Combat Sortie (Playable & Agonizing)
- **Playable Mini-Game**: Switch to the **DEPLOY: LIVE COMBAT SORTIE** tab to engage rogue recon drones, desync commandos, and decoy DRM compliance auditors.
- **True Hitbox Desync**: Drone collision boxes are offset **16px to the left** of their visual sprites. Aiming directly at the visual sprite results in a telemetry miss!
- **Chamber Jamming**: Weapon heats up with each discharge. Jammed clear lever drifts away from the cursor and requires 3 manual pulls to clear.
- **Manual 2-Step Reload**: Eject brass, then seat casing with an ammunition tax.
- **Mid-Combat Captchas**: Hostile telemetry prompts player to solve arithmetic mid-skirmish to regain trigger authority.
- **Real Loot Drops**: Completing a wave awards authentic tactical assets that integrate directly into the chaotic diagonal inventory cluster.

## 🚀 Live Demo & Deployment

This project is built using vanilla HTML5, CSS3, and JavaScript with Web Audio API synthesis—requiring zero external runtime build tools or dependencies.

### Deploying to GitHub Pages:
1. Navigate to **Repository Settings** > **Pages**.
2. Under **Build and deployment** > **Branch**, select `main` (or `master`) and `/ (root)`.
3. Click **Save**. Your site will be live at:
   `https://NiruBuilds.github.io/Hackathon/`

Simply clone and open `index.html` in any modern web browser:
